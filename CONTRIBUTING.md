# Contribution guide

Treat all research and design as falsifiable. Open one change set per theme; cite original sources; do not copy copyrighted papers into a public repo without redistribution rights. Existing reviews must clearly distinguish verified text from inference. Preserve IDs and decision links. Check links, source manifests and JSON schemas. Never include credentials, private communications or real personal data in fixtures. Avoid GitHub Actions requiring paid runners; local validation scripts are sufficient.

## Definition of done for an individual review
Authentic bibliographic identity; source record; methods; assumptions; findings; limitations; counterexamples; derived Routin implications; connected papers and ADRs; proposed tests; explicit access status and review date.
