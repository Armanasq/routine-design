# Paper sources

Each paper has an independent `SOURCE.md` in `papers/<topic>/<paper-id>/`, with bibliographic details, the official source URL, explicit access status, acquisition instructions, and licensing precautions.

**Current verified acquisition status: 35 source records, zero locally downloaded PDF/TeX files.** This environment does not provide outbound file-download access. Source pointers are not paper texts. A number of linked official PDFs are openly readable, but redistribution rights must be verified independently. Do not commit unlicensed copyrighted sources to this public repository.

The machine-readable index is [catalog.json](catalog.json). Local source fetching with license-check gating is described in [acquisition.md](acquisition.md). Use `python scripts/verify_corpus.py` to validate all review/source pairs.

Source files should be named `paper.pdf`, `source.tex`, or `source.html` where the rights permit, and accompanied by `ACQUISITION.json` containing URL, version, SHA256, license and date.
