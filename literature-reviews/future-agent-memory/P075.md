# P075: StreamMemBench: Streaming Evaluation of Agent Memory for Future-Oriented Assistance

**Authors:** Guanming Liu, Yuqi Ren, Hansu Gu, Peng Zhang, Weihang Wang, Jiahao Liu, Ning Gu, Tun Lu  
**Year/venue:** 2026; Findings of EMNLP 2026  
**Canonical source:** https://aclanthology.org/2026.findings-emnlp.992/  
**Access level:** acl_abstract_and_arxiv_introduction_html. The available abstracts and selected sections were inspected, but this is NOT a claim of exhaustive full-text analysis.

## What was studied and how
Creates initial and related follow-up tasks around evidence anchors from egocentric observation streams. Separates evidence recall, evidence use in the current task, user-feedback incorporation and future reuse. Compares eight memory systems across two model backbones.

## What the evidence supports
Several systems can store observations or incorporate feedback locally but fail to use them reliably in subsequent assistance. This directly tests the mechanism needed for a personal secretary that learns during integrations.

## Boundaries and alternative explanations
Streaming egocentric evidence is not equivalent to all mail/calendar/social workflows; benchmark episodes and feedback validity may not capture permissioned actions or longitudinal user aspirations.

## Architectural inference for Routin (a hypothesis, not a study finding)
Keep observation memory, inference and behavior realization independent. Store real feedback with exposure provenance, then test whether later related decisions improve; do not score only memory recall.

## Consequential experiment and negative case
Introduce streaming event sequences with corrections, source gaps and changed user context. Test initial use and future transfer separately, with ablations for source/temporal validity filtering and memory promotion.

## What must be checked before a publication-grade claim
Inspect exact version, methods and results, sampling/selection, full tables/figures, statistics, comparison systems and counterexamples. Record stronger conflicting evidence if found. The research only informs the proposed controller; none of these papers independently demonstrates a universal, safe personal secretary or Routin's empirical benefit.
