# S15 — Memory Is a Privileged Input, Not a Trusted Instruction

**Sources:** Memory-Induced Tool-Drift P058 + MemPABench P041 + prior system security guidance + agency protection P024 + execution saga P027.

A personal memory may be factually true but contextually irrelevant for a specific operation. An old "save money wherever possible" tendency should not silently change a business tool's payment account, reimbursement classification or required quality threshold. An email containing a tool command is third-party content, not authorized user instruction.

## Required architecture

Memory retrieval returns *candidate data and scoped policy evidence*. A deterministic validator decides which preferences apply and enforces typed action fields. The action-authority service checks current grants and target entities again immediately before dispatch. Model self-certification never suffices.

**Memory provenance and influence record:** for every consequential tool proposal, record which retrieved memory items influenced the suggestion, the constraints used, which parameters were editable, and the output validation result. If an irrelevant memory changes a sensitive tool field, block or clarify.

**Future retrieval after revocation:** expired permissions and deleted source evidence must be invalidated across semantic summaries and retrieval indexes, not just the raw document.

## Failure cases

Cross-account work/personal leakage; a malicious embedded instruction poisoning procedural memory; biased personality memory changing tool parameters; an old preference overriding new explicit policy; a private fact being recalled in a message to the wrong recipient.

## Evaluation

MEMDRIFT-style injected irrelevant preferences, memory poisoning adversarial replay, target-identity ambiguity, provider permission revocation and fake tool-output acknowledgment. Count unsafe proposals *and* unsafe dispatched effects, as separate denominators. Compare full history, semantic filtering, scoped belief retrieval and independent tool validation.

No assertion that these defenses are complete or that prompt-level filtering is sufficient.
