# S16 — General Coordination and Domain-Specific Truth

**Sources:** P059 (health agent specialist evaluation), P060 (longitudinal agency), P036/P037 (social coordination), P041 (contextual preference realization), P069 (composable intervention templates).

## Derivation

Executive secretarial and coordination work has reusable structure: a user end, parties, dependencies, deadlines, evidence and next actions. This structure recurs in work, exercise, educational practice and application workflows.

But the *meaning of progress* changes by domain. A student finishing notes may still lack mastery; a portal uploading a form does not establish submission; an emailed invitation does not show agreement; a weekly gym schedule does not establish improved health. Generic task state and one completion detector therefore create false certainty.

A 2026 Nature personal-health-agent study separates numerical data analysis, medical-domain reasoning and coaching because these capabilities need different knowledge and evaluations. The 2026 longitudinal-health framework distinguishes coherence, continuity, adaptation and agency across changing personal circumstances. These provide strong related prior art for modularity, not evidence that Routin's design is original.

## Decision architecture

Shared kernel owns consent, temporal responsibility and goal graph, global coordination and verified transitions. Domain pack supplies specialist predicates: authoritative sources, observation types, outcome verifier, risk envelope, valid intervention modes and constraints. External effects remain gated by independent runtime authorization.

## Hazard and counterexample

A universal "task done" state based on generated text would declare a medical issue resolved after providing a symptom answer. A domain-isolated health agent might coordinate its appointment without considering the user's accepted work commitments. Correct behavior requires both common scheduling awareness and specialist interpretation without over-disclosing private details.

## Falsification

Hold models/tools constant; evaluate generic task engine vs domain-composable packs in novel mixed-domain scenarios. Measure false outcomes, user intent preservation, unauthorized disclosure, competency error and net user burden. Include a no-pack safe fallback.
