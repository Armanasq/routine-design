# P078: ToolSandbox: A Stateful, Conversational, Interactive Evaluation Benchmark for LLM Tool Use Capabilities

**Authors:** Jiarui Lu, Thomas Holleis, Yizhe Zhang, Bernhard Aumayer, Feng Nan, Felix Bai, Shuang Ma, Shen Ma, Mengyu Li, Guoli Yin, Zirui Wang, Ruoming Pang  
**Year/venue:** 2024; arXiv:2408.04682 (preprint)  
**Canonical source:** https://arxiv.org/abs/2408.04682  
**Access level:** arxiv_abstract_and_selected_introduction. The available abstracts and selected sections were inspected, but this is NOT a claim of exhaustive full-text analysis.

## What was studied and how
Models stateful tool execution with implicit dependencies, simulated on-policy user interactions and dynamic milestone scoring along arbitrary action trajectories. Scenarios explicitly include canonicalization, state dependencies and insufficient information.

## What the evidence supports
Shows that multi-step state and information insufficiency challenge tested tool-calling models. A correct final statement does not establish correct intermediate action sequence.

## Boundaries and alternative explanations
ToolSandbox uses simulated state and tool primitives, not a consented lifelong user with changing preferences; safety-specific external harms are not measured directly.

## Architectural inference for Routin (a hypothesis, not a study finding)
Build a world-state simulator with evidence visibility and intermediate postconditions. Runtime planners must ask for missing information rather than silently fill it; tools and permissions can change at each step.

## Consequential experiment and negative case
Inject missing arguments, state changes and delayed source updates. Compare milestone correctness and terminal verified outcomes, not only final natural-language success.

## What must be checked before a publication-grade claim
Inspect exact version, methods and results, sampling/selection, full tables/figures, statistics, comparison systems and counterexamples. Record stronger conflicting evidence if found. The research only informs the proposed controller; none of these papers independently demonstrates a universal, safe personal secretary or Routin's empirical benefit.
