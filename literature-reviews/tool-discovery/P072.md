# P072: Tool Recommendation for Multi-Step Agents: Finding Every Tool a Task Needs

**Authors:** Sam Partee, River Stevens, Thierry Damiba, Valerie Fanelle  
**Year/venue:** 2026; arXiv:2610.23707 preprint  
**Canonical source:** https://arxiv.org/abs/2610.23707  
**Access level:** arxiv_abstract_and_selected_introduction. The available abstracts and selected sections were inspected, but this is NOT a claim of exhaustive full-text analysis.

## What was studied and how
Studies a deployed tool recommendation gateway using a catalog with approximately 8,200 tool definitions that do not fit model context. Through three stable tools, it retrieves candidate operations and mediates calls with end-user credentials and per-agent consent, evaluating retrieval and a small set of billed end-to-end sessions.

## What the evidence supports
Reports all-required-tool recall in top ten 57% above BM25 on ToolRet and first recommendation tool coverage in 93% of Codex sessions; input-token savings are observed against a fixed tool list in the paired study. These are platform-specific results, not guaranteed general transfer.

## Boundaries and alternative explanations
Industrial platform authors evaluate their own system; several paired cost runs, catalog distribution and fixed baseline are not a representative set of personal secretary tasks. High recall does not prove workflow completion, tool safety or grant correctness.

## Architectural inference for Routin (a hypothesis, not a study finding)
Keep capability discovery outside core prompt and preserve gateway-level identity/permission binding. Re-retrieve when task unfolds rather than assume the initial tool set is complete. Separate discoverability from grants.

## Consequential experiment and negative case
Measure recall of complete multi-step tool set, ineligible tool recommendations, user grant mismatches, dynamic add/remove and cost across domains. Compare BM25, vector, abstract needs, hybrid selection and naive all-tools context.

## What must be checked before a publication-grade claim
Inspect exact version, methods and results, sampling/selection, full tables/figures, statistics, comparison systems and counterexamples. Record stronger conflicting evidence if found. The research only informs the proposed controller; none of these papers independently demonstrates a universal, safe personal secretary or Routin's empirical benefit.
