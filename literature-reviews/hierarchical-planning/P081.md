# P081: SHOP2: An HTN Planning System

**Authors:** Dana S. Nau, Tsz-Chiu Au, Okhtay Ilghami, Ugur Kuter, J. William Murdock, Dan Wu, Fusun Yaman  
**Year/venue:** 2003; Journal of Artificial Intelligence Research 20, 379–404  
**Canonical source:** https://doi.org/10.1613/jair.1141  
**Access level:** journal_abstract_and_institutional_description. The available abstracts and selected sections were inspected, but this is NOT a claim of exhaustive full-text analysis.

## What was studied and how
Formal hierarchical task network planning system recursively decomposes tasks using methods until primitive operators can be applied; includes temporal and metric planning features and reports performance in 2002 planning competition.

## What the evidence supports
Shows compositional planning with operators and method descriptions predates modern LLM agents. Domain methods are modeled as data/logic and need not be one bespoke workflow per prompt.

## Boundaries and alternative explanations
SHOP2 requires a defined planning domain/valid methods, so it is not automatically a solver for any unknown real-world objective. State can be partially observed and provider effects uncertain; naive classical preconditions assume known facts.

## Architectural inference for Routin (a hypothesis, not a study finding)
Routin should use effect/precondition-aware planning and validated reusable methods for familiar structures, while leveraging model reasoning to propose new decompositions; unresolved tool gaps cannot be filled by hallucinated operators.

## Consequential experiment and negative case
Test dynamic operator addition/removal and leave-domain-out goals; compare hardcoded task names, naive LLM execution and operator-based composition. Record search incompleteness separately from true unsupported capability.

## What must be checked before a publication-grade claim
Inspect exact version, methods and results, sampling/selection, full tables/figures, statistics, comparison systems and counterexamples. Record stronger conflicting evidence if found. The research only informs the proposed controller; none of these papers independently demonstrates a universal, safe personal secretary or Routin's empirical benefit.
