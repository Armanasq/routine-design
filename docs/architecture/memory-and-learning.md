# Personal Operating Model: memory and learning

## Layers
1. **Evidence:** source revisions, retention, consent and provenance.
2. **Working:** current operation/turn, short-lived.
3. **Episodic:** interventions, choices, corrections, outcomes, exceptional circumstances.
4. **Semantic:** goals, relationships, projects, belief statements and evolving preferences.
5. **Procedural:** approved, versioned, tested tool procedures; NEVER arbitrary executable instructions from messages.
6. **Calibration and self-impact:** forecasts vs outcomes, presentation-policy exposure, false assumptions, source coverage.

## Write pipeline
Observe -> extract candidate -> resolve entities -> validate proposition -> compare with scoped current beliefs -> keep as hypothesis / confirm / supersede -> append evidence and lineage -> invalidate caches -> trigger affected decisions.

## Preference precedence
Explicit current instruction and current authority constraints > scoped confirmed preference > uncertain inferred preference > observed pattern. A later observation cannot silently overrule explicit intent. Temporary exceptions do not rewrite the global rule.

## Learning eligibility
A click, silence, dismissal, or completion is not necessarily positive preference feedback. Record prior exposure and whether the user actually had a choice. Restrict live exploration to reversible low-risk attention decisions. Use inverse-propensity scoring only with logged, correct propensities and overlap.

## Drift taxonomy
Source staleness vs inconsistent observations vs contextual exceptions vs temporary change vs persistent value change. Evidence type determines remedy: source resync, inference retry, short clarification, temporal revision, or user confirmation.

## Retrieval
Filter current validity/tenant/permission first; then search source-backed facts. Do not retrieve obsolete claims just because embedding similarity is high. Include source freshness, contradiction and confidence in answer context. Ask or abstain on consequential uncertainty.

## Release tests
Synthetic evolving preferences; forgotten/revoked sources; conflicting explicit vs observed habits; false person merge; one-time exception; temporal query; never retrieve superseded preference for current action.

Research basis: Memora (ACL 2026); LongMemEval (ICLR 2025); distributed cognition (Hollan et al., 2000); biased feedback (Schnabel et al., 2016).
