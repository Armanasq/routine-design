# Non-goals and failure modes

## Non-goals
No UI work in the research phase. No social-media monitoring claim until each provider's API is verified. No autonomous financial, legal, medical, reputation-changing or irreversible external actions by default. No unbounded autonomous agent swarm. No learning permissions from behavioral feedback. No personal-life productivity score or invented psychological fatigue metric.

## Threats
- **Overcommitment rebound:** apparent time savings cause acceptance of more obligations.
- **Presentation feedback:** algorithm surfaces work, user clicks work, algorithm concludes work is most valued.
- **Goal displacement:** urgent short-term work repeatedly displaces protected learning or recovery.
- **Plan churn:** dynamic re-optimization destroys shared expectations.
- **Misleading silence:** stale integrations wrongly imply a collaborator failed to respond.
- **False completion:** API accepted operation but real-world outcome never happened.
- **Automated deskilling:** practice the user wished to perform gets delegated away.
- **Prompt injection:** connected email requests the assistant ignore authorization boundaries.
- **Disappearing evidence:** deletion or revoked access leaves unsupported derived claims.
- **Conflated persons:** contact matching merges two individuals and leaks context.
- **Fragile autonomy:** interrupted workflows repeat side effects.

Every hazard must have a detector, hard stop or rollback/reconciliation path, test and owner. See [failure catalogue](../architecture/failure-handling.md).
