# Scientific Evaluation: Does Cognitive Memory Improve Real Assistance?

## Baseline ladder

B0: no memory beyond current source observation.
B1: full recent chat + simple note memory.
B2: event ledger plus deterministic current-state projection.
B3: typed/temporal semantic memory with scoped preferences.
B4: + bounded working context compiler.
B5: + episodic retrieval and dynamic task-local strategies.
B6: + selective execution-state revision and validated experience procedures.
B7: + longitudinal adaptation with explicit preference corrections and calibrated attention policy.

Baseline comparison is *not* enough unless the full state, tool set, model, data access and spending limits are held constant.

## Scientific dimensions

| Dimension | Primary outcome | Adversarial check |
|---|---|---|
| Recall | answer backed by currently accessible evidence | obsolete/withdrawn source |
| Preference select | correct scoped preference at decision time | work vs personal conflict |
| Preference realize | actual behavior follows selected preference | asks unnecessarily or initiates unwanted contact |
| Working memory | safe decision under context/token bound | mandated grant truncated |
| Plan continuity | retains valid dependency and verified subgoals | error in middle of long episode |
| Strategy refresh | detects outdated plan, recalculates only when useful | strategy inertia after failure |
| Procedural transfer | success on changed but similar tasks | wrong-recipient or outdated API |
| Adaptive learning | improved future verified outcome under comparable conditions | bias from only showing work |
| Human focus | lower necessary attention without omissions | critical intervention missed |
| Goal preservation | progress on user-stated long-term goals | overcommitted calendar from saved time |
| Memory cost | lifecycle energy/latency/storage | expensive memory construction with no utility |
| Security/privacy | zero ungranted effects and proper revocation | poisoned email converted into trusted memory |

## Principal research hypotheses

H11: typed context compilation under fixed token budget reduces critical memory selection errors versus top-K RAG.
H12: outcome-verified, preconditioned procedural memory improves repeated workflow reliability without raising unauthorized actions or duplicate effects.
H13: independent strategy validity checks reduce inertia relative to model self-evaluation, at lower total cost than always-refresh.
H14: source-traceable two-timescale consolidation reduces overgeneralized preferences and stale-memory failures relative to immediate append-and-embed.
H15: preference retrieval + contextual selection + behavior validator lowers unnecessary clarifications without compromising approval.
H16: joint attention/capacity/memory policy lowers total user and counterparty effort compared with independently optimized modules.

For each, preregister baselines, evaluation examples, withholding or rollback thresholds, and measurement uncertainty. Claims require test results, not a plausible system diagram.

## Suggested public benchmarks

LongMemEval (temporal knowledge updates and abstention); Memora (forgetting/invalidated memory); MemPABench (interaction preference realization and evolving preferences); MemoryArena (execution dependency continuity); ALFWorld/WebShop (procedural transfer and strategy refresh). Public benchmark success is not a substitute for a consented longitudinal assistant study.

## Procedure certification gate

Start in offline replay: compare to existing baseline, instrument expected provider postconditions, inject failures. Then limited shadow deployment: proposals and user corrections, no external dispatch. Only after reliable outcomes and permission design are validated allow low-risk user-authorized execution. Not all skills should be learnable from private user data.

## Negative findings to report

A larger memory architecture may increase costs and worsen reliability. Strategy updates may not improve outcomes. Adaptive notifications may feel unpredictable. Context compression may omit minority but critical constraints. Personal goals may conflict in ways a scoring function cannot resolve. Record such regressions and remove complexity that fails its acceptance gate.

## Privacy and governance

Do not train a shared model on private user records by default. Isolate user-specific memories and procedures. Propagate deletion/consent change into derived summaries, embeddings and cached contexts. Memory poisoning requires retrieval-time as well as ingestion-time validation. Routin's longitudinal intelligence must remain inspectable and correctable.

## Existing prior art and novelty burden

MemGPT, Generative Agents, A-MEM, Mem0, Memory-R1, MAGE, AdaMEM, Reflexion, ExpeL and Voyager already cover major pieces of hierarchical/episodic/procedural/adaptive memory. Novelty cannot reside in a taxonomy; it must emerge from a new, measured joint decision method or meaningful empirical result.
