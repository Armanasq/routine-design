# Open-world task scenario seeds

[100 human-readable cases](universal-100.md) · [100 machine-readable evaluation seeds](universal-100.json).

These **100 examples are not runtime conditions or scripted skills**. Each is a cross-domain test seed. Convert to runnable fixtures by synthesizing a new world state, verified capabilities, a permission model, conflicting events and outcome oracles. Keep task IDs out of agent prompts and implementations. Domain leave-out and tool leave-out splits are required to evaluate genuine generalization; paraphrases of seen cases are not sufficient. See [adaptive backbone](../../docs/backbone/00-practical-intelligence-architecture.md).
