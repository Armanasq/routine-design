# ADR-0016 — Learning Must Improve Future Outcomes, Not Just Store Memories

**Status:** research design principle.

Online experience is entered as source-backed episodes and user corrections, with explicit feedback exposure and uncertainty about causal explanations. Generalization becomes an optional tested procedure and scoped memory update. State must be revertible. A human's stated values or grants cannot be overridden by learned patterns.

Prior art: CL-Bench P074, StreamMemBench P075, CLE P076, Agent Lightning P079. Baselines include no-memory reset and in-context-only learning, which can outperform specialized memory systems. The mechanism is rejected if later-task outcome accuracy or user burden does not improve at matched cost/risk.
